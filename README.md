# Lumadio releases

Official downloads of Lumadio for macOS (the direct version), made by Genjux.

Download the latest `.dmg` from [Releases](https://github.com/PetrGuan/Lumadio-releases/releases/latest). Every build is signed with a Developer ID certificate and notarized by Apple.

- Requires macOS 14.2 or later on Apple silicon.
- Lumadio is also on the Mac App Store. The direct version adds hardware display control (DDC), Night Shift, brightness sync and other features that the App Store does not allow.
- Support: genjux1024@gmail.com

This repository holds release files only; it does not contain source code.
